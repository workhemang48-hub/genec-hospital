# 🏥 Genec Hospital — Hospital Management System

A Full-Stack Hospital Management Website built using the MERN Stack (MongoDB, Express.js, React.js, Node.js).

🔴 **Live:** https://genec-hospital.vercel.app/

---

## 📌 Project Overview

Genec Hospital is a full-stack hospital management platform designed to streamline patient records, appointment booking, and doctor/department management for healthcare providers. This project is a MERN-based rebuild of an earlier PHP/MySQL hospital management system, focused on a faster, more scalable, and fully live deployment.

## ⚙️ Installation Guide

1. Clone the repository:
```
git clone https://github.com/workhemang48-hub/genec-hospital.git
```

2. Install dependencies:
```
cd server && npm install
cd ../client && npm install
```

3. Set up environment variables (MongoDB URI, etc.) in a `.env` file in the `server/` folder.

4. Run the backend:
```
cd server && npm start
```

5. Run the frontend:
```
cd client && npm start
```

6. Or simply visit the live site:
```
https://genec-hospital.vercel.app/
```
